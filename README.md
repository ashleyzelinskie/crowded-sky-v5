# Crowded Sky v5 (work in progress, not deployed)

- `autonomous-v5.html` is the gallery display. Open it with `#gallery=<key>` on the gallery machine. With no key it never writes to the companion feed.
- `companion-v5.html` is the phone companion.
- `aesthetic-tests/` holds the relief, bronze and palette test layers, not yet folded in.
- `V5_HANDOFF.md` covers status, decisions and next steps.

This is a snapshot for sharing. The live work runs from Ashley's site, which provides the catalog proxy (`/api/catalog`) and the fallback data file (`../orbital_data_v3.json`); opened from here it falls back to CelesTrak data.
